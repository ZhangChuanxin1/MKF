# Experiment map

All commands below are run from the repository root. Heavy and opt-in tests
are not launched by the default smoke profile.

## 1. MKF and KKLSS correctness

The `software` profile runs, sequentially with `GOMAXPROCS=1`:

- MKF-CKKS P1 correctness
- MKF-BFV P1 correctness
- KKLSS MK-CKKS correctness
- KKLSS MK-BFV correctness
- a small flooding replay when NumPy is installed

```powershell
pwsh -NoProfile -File scripts/run_suite.ps1 -Profile software
```

## 2. CPU profiling and attribution

The bundled `software/kklss` tree already includes the KKLSS single-threaded
profiling instrumentation and profiling tests. The patch kit in
`experiments/cpu/kklss_exact_tests` records how to apply the same
instrumentation to a separate compatible upstream checkout and includes the
summarizers. The MKF profiling and table scripts are in
`software/mkf/stageprof` and `software/mkf/scripts`.
Treat stage values as measured only when generated by an instrumented run;
never populate a table from proportional allocation or a different platform.

## 3. Noise and flooding

- MKF noise tests: `software/mkf/mkf_cpu/noise_experiment_test.go`
- KKLSS noise tests: `software/kklss/mkckks/noise_experiment_test.go` and
  `software/kklss/mkbfv/noise_experiment_test.go`
- Flooding replay: `experiments/flooding/simulate_uniform_flooding.py`

The checked-in CSV is an input to the flooding replay. Generated outputs go
under `.local/` and are not publication evidence until their provenance is
reviewed.

## 4. ResNet-20 software path

The MKF module includes functional ResNet-20 executors and correctness tests.
Large full-network invocations are guarded by explicit environment variables
inside the tests. The default suite does not run them. The U55C hardware tree
does not include a full-network operand, payload, address, HBM or XRT runtime
contract, so software ResNet-20 results cannot be presented as U55C results.

## 5. Security-estimator tools

The Sage-compatible scripts in `experiments/security` generate or evaluate
candidate parameter sets. Run them in the estimator environment required by
their imports and retain the estimator revision, command line, input and raw
output. This repository does not embed a substituted security result.

## 6. U55C HLS primitive validation

Generate fixtures once, then run C simulation for all four targets:

```powershell
pwsh -NoProfile -File scripts/generate_fixtures.ps1 -AllowLargeOutput
pwsh -NoProfile -File scripts/run_suite.ps1 -Profile u55c-csim
```

Run one target directly when debugging:

```powershell
pwsh -NoProfile -File scripts/run_u55c_hls.ps1 `
  -Target mkf_ckks -Mode csim -ClockProfile smoke
```

The output is HLS evidence only. Board measurement remains a separate,
currently unimplemented layer.
